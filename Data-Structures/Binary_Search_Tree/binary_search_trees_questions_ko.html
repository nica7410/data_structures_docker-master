섹션 F - 이진 탐색 트리

Binary Search Trees Questions - 한글 번역본

안내: 이 섹션에서는 지정된 문제 1개에 답합니다. 문제용 프로그램 템플릿은 APAS 시스템에서 제공되며, 반드시 해당 템플릿을 사용하여 함수를 구현해야 합니다.

1. levelOrderTraversal - 레벨 순회

큐(queue)를 사용하여 이진 트리를 루트 레벨부터 레벨별로 순회하여 출력하는 반복형(iterative) C 함수를 작성하세요.

큐에 정수를 추가하거나 제거할 때는 enqueue()와 dequeue() 연산만 사용해야 합니다. 함수 시작 시 큐가 비어 있지 않다면 먼저 큐를 비워야 합니다.

함수 원형

void levelOrderIterative(BSTNode *root);

그림 1의 이진 트리에 대한 레벨 순회 결과는 다음과 같습니다. 

20, 15, 50, 10, 18, 25, 80
레벨 순회는 위에서 아래로, 같은 레벨에서는 왼쪽에서 오른쪽 순서로 방문합니다.

2. inOrderIterative - 반복형 중위 순회

스택(stack)을 사용하여 이진 탐색 트리를 중위 순회(in-order traversal)하여 출력하는 반복형 C 함수 inOrderIterative()를 작성하세요.

스택에 정수를 추가하거나 제거할 때는 push()와 pop() 연산만 사용해야 합니다. 함수 시작 시 스택이 비어 있지 않다면 먼저 스택을 비워야 합니다.

함수 원형

void inOrderIterative(BSTNode *root);

그림 2의 이진 트리에 대한 반복형 중위 순회 결과는 다음과 같습니다. 

10, 15, 18, 20, 50
중위 순회 순서: 왼쪽 서브트리 → 현재 노드 → 오른쪽 서브트리

3. preOrderIterative - 반복형 전위 순회

스택(stack)을 사용하여 이진 탐색 트리를 전위 순회(pre-order traversal)하여 출력하는 반복형 C 함수 preOrderIterative()를 작성하세요.

스택에 정수를 추가하거나 제거할 때는 push()와 pop() 연산만 사용해야 합니다. 함수 시작 시 스택이 비어 있지 않다면 먼저 스택을 비워야 합니다.

함수 원형

void preOrderIterative(BSTNode *root);

그림 3의 이진 트리에 대한 반복형 전위 순회 결과는 다음과 같습니다. 

20, 15, 10, 18, 50, 25, 80
전위 순회 순서: 현재 노드 → 왼쪽 서브트리 → 오른쪽 서브트리

4. postOrderIterativeS1 - 스택 1개를 이용한 반복형 후위 순회

스택 하나를 사용하여 이진 탐색 트리를 후위 순회(post-order traversal)하여 출력하는 반복형 C 함수 postOrderIterativeS1()을 작성하세요.

스택에 정수를 추가하거나 제거할 때는 push()와 pop() 연산만 사용해야 합니다. 함수 시작 시 스택이 비어 있지 않다면 먼저 스택을 비워야 합니다.

함수 원형

void postOrderIterativeS1(BSTNode *node);

그림 4의 이진 트리에 대한 반복형 후위 순회 결과는 다음과 같습니다. 

10, 18, 15, 25, 80, 50, 20
후위 순회 순서: 왼쪽 서브트리 → 오른쪽 서브트리 → 현재 노드

5. postOrderIterativeS2 - 스택 2개를 이용한 반복형 후위 순회

스택 두 개를 사용하여 이진 탐색 트리를 후위 순회(post-order traversal)하여 출력하는 반복형 C 함수 postOrderIterativeS2()를 작성하세요.

각 스택에 정수를 추가하거나 제거할 때는 push()와 pop() 연산만 사용해야 합니다. 함수 시작 시 스택들이 비어 있지 않다면 먼저 모두 비워야 합니다.

함수 원형

void postOrderIterativeS2(BSTNode *root);

그림 5의 이진 트리에 대한 반복형 후위 순회 결과는 다음과 같습니다. 

10, 18, 15, 25, 80, 50, 20
이 문제는 4번과 같은 후위 순회 결과를 만들지만, 구현할 때 스택을 두 개 사용한다는 점이 다릅니다.

1. identical - 두 이진 트리가 동일한지 확인

두 이진 트리를 tree1과 tree2라고 할 때, 두 트리가 구조적으로 동일한지 판단하는 재귀 C 함수 identical()을 작성하세요. 두 트리가 구조적으로 동일하면 1을, 그렇지 않으면 0을 반환합니다.

두 이진 트리가 모두 비어 있거나, 또는 둘 다 비어 있지 않으면서 왼쪽 서브트리와 오른쪽 서브트리가 서로 동일하면 두 트리는 구조적으로 동일합니다. 즉, 노드의 값이 같고 같은 방식으로 배치되어 있어야 합니다.

함수 원형

int identical(BTNode *tree1, BTNode *tree2);

예를 들어 그림 1의 두 트리는 모두 중위 순회 결과가 (1, 3, 2, 5, 4, 7, 8)이고 구조와 값의 배치도 같으므로 구조적으로 동일합니다.

원문에 적힌 참고 메모 번역:
  • 둘 다 NULL이면 1을 반환합니다.
  • 둘 중 하나만 NULL이면 0을 반환합니다.
  • 두 노드의 item 값이 다르면 0을 반환합니다.
  • 그 외에는 왼쪽과 오른쪽 서브트리를 각각 검사한 결과를 이용합니다.
예시 입력/출력 번역 보기 
1: 이진 트리 tree1 생성
2: 이진 트리 tree2 생성
3: 두 트리가 구조적으로 동일한지 확인
0: 종료

2. maxHeight - 이진 트리의 최대 높이

이진 트리 루트 노드를 가리키는 포인터를 받아, 루트에서 가장 멀리 있는 리프 노드까지의 가장 긴 경로에 포함된 링크(간선)의 개수를 반환하는 C 함수 maxHeight()를 작성하세요.

특정 노드의 높이는 그 노드에서 가장 깊은 리프 노드까지의 링크 개수입니다. 빈 트리의 높이는 -1이라고 가정합니다.

그림 2의 이진 트리 (1, 2, 3, 4, 5, 6, 7)의 최대 높이는 2입니다.

원문에 적힌 참고 메모 번역:

  • 그렇지 않으면 왼쪽 서브트리와 오른쪽 서브트리의 높이를 비교하고, 더 큰 값에 1을 더해 반환합니다.

5. mirrorTree - 이진 트리를 좌우 반전

기존 이진 트리를 수정하여 원래 구조의 거울상(mirror image)이 되도록 만드는 재귀 C 함수 mirrorTree()를 작성하세요. 중간용 또는 임시 트리를 새로 만들면 안 됩니다. 함수는 반전할 이진 트리의 루트 노드 포인터 하나를 매개변수로 받습니다.

함수 원형

void mirrorTree(BTNode *node);

그림 5의 왼쪽 트리의 중위 순회 결과는 (5, 6, 4, 3, 2, 1)이고, 좌우 반전 후 오른쪽 트리의 중위 순회 결과는 (1, 2, 3, 4, 6, 5)입니다.

원문에 적힌 참고 메모 번역:
  • node == NULL이면 반환합니다.
  • BTNode *temp와 같은 임시 포인터를 사용하여 현재 노드의 왼쪽/오른쪽 자식 포인터를 서로 바꿉니다.
  • 그다음 mirror(node->left), mirror(node->right)처럼 양쪽 서브트리에 대해 재귀적으로 처리합니다.

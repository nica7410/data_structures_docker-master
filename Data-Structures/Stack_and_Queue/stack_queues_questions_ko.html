1. createQueueFromLinkedList

연결 리스트에 저장된 모든 정수를 차례대로 enqueue하여 연결 리스트 기반의 큐를 만드는 C 함수 createQueueFromLinkedList()를 작성하세요.

연결 리스트의 첫 번째 노드를 먼저 큐에 넣고, 그다음 두 번째 노드, 그다음 세 번째 노드의 순서로 계속 처리합니다. 큐가 비어 있지 않다면 함수 시작 시 먼저 큐를 비워야 합니다.

함수 원형

void createQueueFromLinkedList(LinkedList *ll, Queue *q);

입출력 예시

현재 연결 리스트: 1 2 3 4 5

The resulting linked list is: 1 2 3 4 5
Please input your choice(1/2/3/0): 2
The resulting queue is: 1 2 3 4 5
원문 페이지의 참고 메모: 
ListNode *temp = ll->head;
while (temp != NULL) {
    // 필요한 작업 수행
    temp = temp->next;
}

2. createStackFromLinkedList

연결 리스트에 저장된 모든 정수를 차례대로 push하여 연결 리스트 기반의 스택을 만드는 C 함수 createStackFromLinkedList()를 작성하세요.

연결 리스트의 첫 번째 노드를 먼저 push하고, 그다음 두 번째 노드, 그다음 세 번째 노드의 순서로 계속 처리합니다. 스택이 비어 있지 않다면 함수 시작 시 먼저 스택을 비워야 합니다.

함수 원형

void createStackFromLinkedList(LinkedList *ll, Stack *stack);

입출력 예시

현재 연결 리스트: 1 3 5 6 7

The resulting linked list is: 1 3 5 6 7
Please input your choice(1/2/3/0): 2
The resulting stack is: 7 6 5 3 1
원문 페이지의 참고 메모: 
ListNode *temp = ll->head;
while (temp != NULL) {
    // 필요한 작업 수행
    temp = temp->next;
}

3. isStackPairwiseConsecutive

스택 안의 숫자들이 두 개씩 짝을 이루었을 때 서로 연속된 수인지 검사하는 함수 isStackPairwiseConsecutive()를 작성하세요.

스택에 정수를 추가하거나 제거할 때는 push()와 pop()만 사용해야 합니다.

함수 원형

int isStackPairwiseConsecutive(Stack *s);

예시

스택이 (16, 15, 11, 10, 5, 4)인 경우

The stack is: 16 15 11 10 5 4
The stack is pairwise consecutive

짝은 (16, 15), (11, 10), (5, 4)이고 각 짝의 차이가 1이므로 pairwise consecutive입니다.

스택이 (16, 15, 11, 10, 5, 1)인 경우

The stack is: 16 15 11 10 5 1
The stack is not pairwise consecutive

스택이 (16, 15, 11, 10, 5)인 경우

The stack is: 16 15 11 10 5
The stack is not pairwise consecutive
원문 페이지의 참고 메모:
  • 스택 크기가 홀수라면 0을 반환합니다.
  • 각 숫자 쌍을 확인하고, 조건을 만족하지 않는 쌍이 하나라도 있으면 0을 반환합니다.
  • 모든 쌍이 조건을 만족하면 1을 반환할 수 있습니다.

4. reverseQueue

스택을 사용하여 큐를 뒤집는 C 함수 reverseQueue()를 작성하세요.

스택에 정수를 추가하거나 제거할 때는 push()와 pop()만 사용하고, 큐에 정수를 추가하거나 제거할 때는 enqueue()와 dequeue()만 사용해야 합니다. 스택이 비어 있지 않다면 함수 시작 시 먼저 스택을 비워야 합니다.

함수 원형

void reverseQueue(Queue *q);

예시

큐가 (1, 2, 3, 4, 5)라면 뒤집은 결과는 (5, 4, 3, 2, 1)입니다.
원문 페이지의 참고 메모: 스택을 사용하기 전에 초기화하는 것을 잊지 마세요.

5. recursiveReverseQueue

정수 큐에 저장된 항목의 순서를 뒤집는 재귀 C 함수 recursiveReverseQueue()를 작성하세요.

함수 원형

void recursiveReverseQueue(Queue *q);

예시

큐가 (1, 2, 3, 4, 5)라면 결과는 (5, 4, 3, 2, 1)입니다.
원문 페이지의 참고 코드: 
int temp;

if (q->ll.head == NULL)
    return;

temp = dequeue(q);
recursiveReverseQueue(q);
enqueue(q, temp);

6. removeUntilStack

정수 스택에서 지정한 값이 처음 나타날 때까지 위에서부터 모든 값을 pop하는 C 함수 removeUntilStack()를 작성하세요.

함수 원형

void removeUntilStack(Stack *s, int value);

예시 1

왼쪽에 표시된 숫자가 스택의 top입니다.

스택이 (1, 2, 3, 4, 5, 6, 7)이고 value = 4로 호출하면 결과는 (4, 5, 6, 7)입니다.

예시 2

스택이 (10, 20, 15, 25, 5)이고 value = 15로 호출하면 결과는 (15, 25, 5)입니다.

원문 페이지의 참고 메모:
  • for문도 while문처럼 break할 수 있습니다.
  • s->ll.size == 0인 경우도 고려하세요.

7. balanced

문자 (), [], {}로 이루어진 수식이 괄호 짝이 올바르게 맞는지 판단하는 C 함수 balanced()를 작성하세요.

함수 원형

int balanced(char *expression);

올바르게 균형이 맞는 예

()
([])
{[]()[]}

괄호의 종류, 순서, 개수가 서로 올바르게 대응하므로 balanced입니다.

실행 예시

1: Enter a string:
2: Check whether expressions comprised of the characters ()[]{}
   is balanced:
0: Quit:
Please input your choice(1/0): 1
Enter expressions without spaces to check whether it is
balanced or not: {[]()[]}
{[]()[]}
balanced!
Please input your choice(1/0): 0

균형이 맞지 않는 예

{{)]
[({{)])

균형이 맞지 않는 경우의 실행 예시

1: Enter a string:
2: Check whether expressions comprised of the characters ()[]{}
   is balanced:
0: Quit:
Please input your choice(1/0): 1
Enter expressions without spaces to check whether it is
balanced or not: [({{)])
[({{)])
not balanced!
Please input your choice(1/0): 0
원문 페이지의 참고 메모:
  • 스택을 사용합니다.
  • { [ (와 같은 여는 괄호가 나오면 스택에 push합니다.
  • 닫는 괄호 } ] )가 나오면 스택 top의 여는 괄호와 짝이 맞는지 확인한 뒤, 맞으면 pop합니다.
  • 마지막에 스택이 비어 있는지 확인합니다.
